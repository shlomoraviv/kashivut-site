# קשיבות — בית הספר למיינדפולנס לנשים 🌸

אתר תדמית ומכירה לקורסי Mindfulness לנשים מהציבור הדתי והחרדי.
אתר סטטי (HTML + CSS + JS בלבד) — ללא תלות בשרת או בבסיס נתונים.

## מבנה האתר

| עמוד | קובץ |
|---|---|
| דף הבית | `index.html` |
| קורס MBSR | `mbsr.html` |
| קורס העמקה | `deepening.html` |
| אודות (יעל ברייר) | `about.html` |
| שאלות נפוצות | `faq.html` |
| צור קשר והרשמה | `contact.html` |
| עמוד 404 | `404.html` |

עיצוב: `assets/css/style.css` · סקריפטים: `assets/js/site.js` · תמונות: `assets/img/`

## הפעלה מקומית

פשוט פתחי את `index.html` בדפדפן, או:

```bash
python -m http.server 8791
# http://localhost:8791
```

## 🔴 חובה להפעלה: חיבור הטפסים ל-Formspree

הטפסים בנויים ומוכנים, אך עדיין לא מחוברים לכתובת Formspree אמיתית.
ברגע שתופעל, כל פנייה מהאתר תגיע ישירות למייל שלך.

1. הירשמי בחינם ב-[formspree.io](https://formspree.io) וצרי טופס חדש.
2. העתיקי את כתובת הטופס שתתקבל, למשל: `https://formspree.io/f/abcdwxyz`.
3. פתחי את הקובץ `assets/js/site.js` והחליפי בשורה:
   ```js
   var FORM_ACTION = "https://formspree.io/f/YOUR_FORM_ID";
   ```
   את ה-`YOUR_FORM_ID` בקוד האמיתי — שורה אחת בלבד.
4. בפעם הראשונה, Formspree ישלח מייל אימות — לחצי על Confirm.
5. זהו! כל שלושת הטפסים באתר (בית ← דרך עמודי הקורסים, ועמוד צור קשר) יעבדו.

> עד להפעלה, מי שישלח טופס יראה הודעה מסודרת שהטופס ייפתח בקרוב.

## ✏️ תוכן שמסומן להחלפה

- **עדויות משתתפות** — הטקסטים כרגע לתצוגה בלבד ומסומנים במפורש ("טקסט להחלפה"). החליפי בעדויות אמיתיות ב-`index.html`, `mbsr.html` ו-`deepening.html`.
- **עמוד אודות** — ישנם מקומות עריכה מסומנים בסוגריים: סיפור אישי, מוסד לימודים, שנות ניסיון.
- **תאריכים, מיקום ועלות** — מופיעים כ"יועדכן בקרוב" עד לקבלת הפרטים.
- **מספר וואטסאפ** — מקום מסומן ב-`contact.html`.
